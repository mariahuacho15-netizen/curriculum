# Formulario de Curriculum Vitae (HTML5)

Formulario HTML5 (`enviacurriculo.htm`) para recibir los datos de un currículum:
datos personales, formación y estudios, experiencia profesional (se pueden agregar varias)
y datos complementarios, con foto, validación y declaración final (lugar y fecha).

Al enviar, la página muestra el currículum completo con opción de **imprimir / guardar PDF**.
Los datos se procesan en el navegador (GitHub Pages es un hosting estático, sin servidor).

Ver en línea: `https://TU_USUARIO.github.io/curriculum-form/enviacurriculo.htm`
